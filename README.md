# 🌷 Floral

Floral is a simple flower shop website created as a project to learn HTML and CSS.

I built the website from scratch while learning how HTML and CSS work.

## 🌐 Pages

The website includes:

- `index.html` — Home page
- `produkter.html` — Products and prices
- `kontakt.html` — Contact page

## 🎨 Styling

The website uses CSS for:

- Background and text colors
- Navigation
- Product layouts
- Flexbox
- Spacing between elements

## 🛠️ Built With

- HTML5
- CSS3
- Git
- GitHub Pages

## 📚 What I Learned

While building this project, I learned about:

- HTML tags and elements
- `<head>` and `<body>`
- Links and images
- `<div>` elements
- CSS classes
- Flexbox and `gap`
- Connecting multiple HTML pages
- Using separate CSS files

## 🚧 Project Status

Floral is still a work in progress. I plan to improve the design, add more products, and continue adding features as I learn more HTML and CSS.
